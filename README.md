# Firefly - Codex Pet

> English version: [English](README_EN.md)

银发Q版流萤，青金配色服饰，叶形发饰，温柔粉蓝眼瞳。

## 使用方法

1. 克隆仓库
   ```bash
   git clone https://github.com/Lhy723/firefly-codex-pet.git
   ```
2. 将 `firefly` 文件夹复制到 Codex Pet 皮肤目录
   - macOS/Linux: `~/.codex/pet/`
   - Windows: `%USERPROFILE%\.codex\pet\`
